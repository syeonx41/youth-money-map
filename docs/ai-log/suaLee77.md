- 도구: Claude Code
- 요청: 다른 Claude 대화에서 사전 조사로 만든 정답 프로필 20개로 `profiles.json`을 바꾸고, 엔진이 아직 표현 못 하는 칸(pending)과 가입 중인 상품(expectedOwned)을 테스트에서 처리하고, `npm test` 결과를 원인별로 정리

- 문제: main의 `data/products.json`에는 예시 상품(`sample-*`)뿐이라, 새 프로필을 그대로 넣으면 정답 칸 116개가 모두 '상품 없음'으로 실패해서 "PR 전 `npm test` 통과" 규칙을 지킬 수 없었음. 또 실제 엔진으로는 정답을 한 번도 돌려보지 못한 상태였음
- 해결: 데이터에 없는 상품은 실패 대신 '② 데이터 대기'로 표시하게 했음. 엔진은 사전 조사 조건표(다른 Claude 대화에서 정리)로 만든 임시 상품 데이터(저장소에 넣지 않음)로 따로 돌렸음. 비교한 139칸이 모두 정답과 같았고, 다른 칸은 보류 3칸(P01 신규 가입 종료, P15 중위소득 하한, P19 반올림 후 비교)뿐이라 ① 엔진·types 문제로 정리함. 버팀목 공식 페이지에서 중소·중견기업 취업자의 병역 연장 규정을 확인해 P05 설명 문장만 고쳤음(정답은 그대로)

- 문제: 사전 조사 때 세운 계획에 있던 챗봇 답변 내용 중 일부는 이번에 공식 출처 원문에서 확인되지 않았음. 주택드림 '1인 1계좌'·'2년 이상 유지'·'연 납입 600만원 한도', 미래적금 '일반 중도해지 시 기여금·비과세 없음'이 그랬음. 서울 청년월세 소득 하한(48% 초과)도 서울시 공고 게시판 요약에는 없었음
- 해결: 금융위원회·주택도시기금·서민금융진흥원·서울시 페이지를 직접 확인했음. 확인된 내용만 '기대 답변'에 넣고, 확인 못 한 내용은 질문별 '메모'로 따로 표시함. 서울월세 하한은 서울시 미디어허브(2026-05-04) 원문 "가구당 기준 중위소득 48% 초과~150% 이하"로 확인함
