### 2026-11-14 서울시 청년월세 제대군인 연령 연장을 militaryMaxMonths 36으로 근사

- 역할: ②
- 도구: Claude Code
- 요청: 교차 검증에서 '형식 한계'로 분류된 P06(서울 청년월세 제대군인 연장)에 militaryMaxMonths 36을 넣고, 결정 경위와 근사의 한계를 기록
- 결과: `data/products.json` seoul-youth-rent 나이 조건에 `"militaryMaxMonths": 36` 추가
- 문제: 공고(서울특별시 공고 제2026-1440호 4쪽)의 연장은 복무 1년 미만 40세, 1년 이상~2년 미만 41세, 2년 이상 42세까지인 계단식이고 출생연도 기준이라, 복무 개월 수만큼 만 나이에서 빼는 militaryMaxMonths로는 정확히 표현할 수 없음. 데이터는 정답과 독립적으로 만들려고 처음에는 이 값을 넣지 않았고, 정답 프로필(P06)을 확인한 뒤에 넣기로 결정함
- 해결: militaryMaxMonths 36은 어느 복무 구간에서도 공고보다 연장 폭이 같거나 작아서, 공고상 대상이 아닌 사람을 '가능'으로 잘못 판정하는 경우가 없는 것을 확인하고 사용자가 반영을 결정함. 한계: 복무 1~3년 사이 일부(예: 2026-11-14 기준 복무 18개월인 1984년생 전원과 1985년 초 출생자. 공고상 41세 상한 대상이지만 엔진은 만 나이에서 18개월만 빼서 만 40~41세로 판정)는 공고상 대상인데 '해당 없음'으로 나옴. 출생연도 기준 판정 차이도 그대로 남음
