- 역할: ②
- 도구: Claude Code (Claude Fable 5.1, claude-fable-5-1)
- 요청: products.json의 조건과 엔진 코드를 읽지 않고, 공식 출처(금융위 보도자료, 서민금융진흥원, 주택도시기금 상품 페이지·가이드라인)만 보고 실제 상품 4개 기준 정답 프로필(profiles.json)을 다시 작성하고 npm test로 데이터·엔진과 비교
- 결과: lib/engine/**tests**/profiles.json을 프로필 13개(기본, 나이 상한 초과, 병역 이행자 2종, 소득 경계 3종, 모름 2종, 유주택, 세대원, 도약계좌 보유자, 소득 0원 학생)로 교체. 각 프로필에 공고 근거를 notes로 남김. npm test 결과 78 통과 / 11 실패. 실패 11건은 모두 청년도약계좌 신규 가입 종료를 엔진이 처리하지 못하는 '엔진 미지원'(①이 엔진을 고치면 통과 예정). 버팀목 대출의 조건부 병역 연장(중소·중견기업 재직자만 최대 만 39세)은 types.ts 조건 형식으로 표현할 수 없는 '형식 한계'라 P03의 버팀목 기대값은 제외하고 설명에 이유를 남김. 데이터 오류나 엔진 오류로 분류된 실패는 없음

- 해결: 저장된 PDF를 PyMuPDF로 직접 추출해 가이드라인 원문을 확인함(가입자격: 가입자 본인 무주택, 신고소득 있는 근로·사업·기타소득자 또는 현역병·전역자, 세대주는 비과세 요건일 뿐 가입 요건 아님). 소득 0원 미래적금은 처음엔 추측하지 않고 P13의 expected에서 제외했고, 이후 사용자가 알려준 금융위 보도자료 첨부 PDF(2026-09-30, Q&A 14쪽 '직전연도 소득이 확인되지 않는 경우 가입이 불가능합니다')를 직접 읽어 '해당 없음'으로 확정함. 엔진도 해당 없음으로 판정해 테스트 통과

### 2026-11-13 청년미래적금 소득 조건 출처 표시 추가

- 역할: ②
- 도구: Claude Code
- 요청: 교차 검증 세션이 찾지 못한 청년미래적금 `allowZero: false`의 근거 문장과 출처를 찾고, sourceText에 출처 표시를 추가
- 결과: `data/products.json` 청년미래적금 소득 조건 sourceText에 3쪽 각주("※ 비과세 소득인 육아휴직급여(수당) 또는 병(兵) 급여가 있는 자의 경우도 가입 가능")를 추가하고, 끝에 " (출처: 금융위 2026-10-01 보도자료 첨부 PDF 2쪽, 3쪽, 14쪽)"를 붙임
- 문제: 교차 검증에서 근거 출처가 첨부 PDF에만 있어 추적이 안 되는 문제 발견. 근거 문장이 보도자료 웹페이지 본문에는 없고 첨부 PDF 14쪽 Q&A에만 있었고, sourceUrl은 웹페이지를 가리켜 검증 세션이 찾지 못함. 또 사용자가 요청한 출처 표시는 "3쪽, 14쪽"이었는데 첫 문장("총급여 7,500만원 이하 소득자 또는…")은 2쪽에 있었음
- 해결: 첨부 PDF를 직접 내려받아 문장별 쪽수를 확인하고, 출처 표시를 "2쪽, 3쪽, 14쪽"으로 넣음. `allowZero: false`는 공고에 "소득 0원 불가"라는 직접 문장이 없고 "직전연도 소득이 확인되지 않는 경우 가입이 불가능"을 해석한 값임을 사용자에게 알림
