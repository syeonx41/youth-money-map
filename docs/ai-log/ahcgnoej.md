- 도구: Claude Code
- 요청: ⑤ 배포 사이트 테스트(PR #13)에서 부분 통과로 나온 챗봇 질문 4개 고치기
- 결과: 챗봇 규칙(app/api/chat/prompt.ts)에 혜택 질문(비율·월 한도·만기·계산 예시), 비과세 등 혜택 조건(가입 조건과 차이, 따로 신청, 한도), '해당 없음'일 때 공고에 적힌 다른 제도 안내, 상품마다 다른 나이 계산 안내, 숫자를 자료 그대로 쓰기 규칙 추가. 혜택 자료를 JSON 대신 한 줄씩 넣고 같은 문장으로 근거를 대조. 기본 모델이 혼잡(429·5xx)하거나 20초 넘게 걸리면 다른 모델(gemini-3.1-flash-lite)로 한 번 더 묻도록 함(app/api/chat/route.ts). 테스트 2개 추가
- 문제: Q2는 근거가 0개였음. 혜택을 JSON으로 넣어서 AI가 "이름: 설명" 형태로 인용하면 원문 대조에서 모두 걸러졌음
- 해결: 혜택을 "이름: 설명" 줄로 넣고 그 줄을 대조 원문에도 넣음. 실제 키로 다시 물어 Q2 근거 1~2개가 붙는 것을 확인

- 해결: 혼잡하면 다른 모델로 바로 넘기고, 숫자는 자료 값을 그대로 쓰라는 규칙을 넣은 뒤 Q2·Q3·Q5·Q8을 여러 번 다시 물어 기준 항목이 들어가는 것을 확인. 두 모델이 모두 혼잡할 때는 여전히 오류 안내가 나옴
