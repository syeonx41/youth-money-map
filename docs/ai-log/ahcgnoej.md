- 해결: Claude 호출 부분을 가짜(mock)로 바꾼 테스트로 정상 답변, 거절, 형식 오류, 키 없음(503)을 확인하고, 사용자 입력 원본(생년월일)이 요청에 들어가지 않는지도 확인. 예시 질문 10개 실제 답변 확인은 키 등록 후에 진행

### 2026-11-16 챗봇 AI를 Gemini로 변경하고 예시 질문 10개 실제 확인
- 역할: ④
- 도구: Claude Code, Claude in Chrome
- 요청: 무료로 쓸 수 있는 Gemini API 키를 발급해 챗봇에 연결하고 실제 답변 확인
- 결과: app/api/chat/route.ts를 Google Gen AI SDK(@google/genai) 호출로 바꿈(키 이름 GEMINI_API_KEY, 모델은 GEMINI_MODEL로 변경 가능). 서버 혼잡(503) 같은 일시 오류는 1번 다시 시도. 챗봇 규칙(app/api/chat/prompt.ts)에 답변에 꼭 담을 내용 추가. 가짜 Gemini 테스트 7개로 교체. 예시 질문 10개(+Q7 후속)를 실제 키로 확인해 모두 응답(1~2.5초)
- 문제: 처음 기본 모델(gemini-3.8-flash)은 무료 등급에서 아주 짧은 질문에도 50초를 넘겨 시간 초과(504)가 났음
- 해결: 모델별 응답 시간을 직접 재서, 2초 안에 답하는 gemini-3.5-flash-lite를 기본 모델로 바꿈
- 문제: 첫 실행에서 Q8이 오류(502)였고, 여러 답변이 예시 문서의 '꼭 들어가야 할 것'(판정 이유의 숫자, 다시 입력하는 방법, 공고에 없는 기준이라는 말, 일정 단계 등)을 빠뜨림
- 해결: 서버 로그로 Q8은 Gemini 일시 혼잡(503)인 것을 확인하고 재시도 1번을 넣음. 답변 규칙에 빠뜨린 항목을 일반 규칙으로 추가한 뒤 다시 실행해 Q3·Q6·Q7·Q8·Q9 답변이 기준에 맞게 바뀐 것을 확인
