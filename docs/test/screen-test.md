[정답표](answer-table.md)의 정답 프로필 20개를 실제 화면에 넣어 보는 표예요. 단계 순서대로 무엇을 누르고 입력하는지, 결과 화면에 무엇이 나와야 하는지 적었어요.

- 기준 코드: `main` `636a4e2` (화면 PR #8 포함)
- 2026-11-16에 화면 코드로 20개를 미리 돌려봤고, **모두 정답표와 같았어요** (6번 참고). 화면에서 아래 표와 다르게 나오면 화면 쪽 문제예요.
- 시작: 첫 화면 **"내 조건으로 찾기"** → 1~5단계 입력 → **"결과 보기"**

## 4. 정답표와 다르게 보여도 정상인 것

화면은 정답표(엔진 판정)를 그대로 보여주지 않고 몇 가지를 걸러서 보여줘요. 아래는 화면 설계대로라서 정상이에요.

- **청년도약계좌 카드가 안 보여요.** 신규 가입이 끝난 상품은 가입 중일 때만 카드가 나와요. 정답표 P01의 도약계좌 ×는 화면에 카드가 없는 게 정상이고, P02에서만 '가입 중' 카드로 나와요. 5단계 목록에는 도약계좌 이름 밑에 "2025년 12월 신규 가입 종료"가 보여요.
- **중복 경고 개수가 정답표보다 적어요.** 경고 띠는 '가능'·'확인 필요' 카드에만 보여줘요.
  - P08: 정답표는 미래적금·버팀목·월세대출 3개 → 화면은 **2개**예요. 버팀목은 '해당 없음'이라 띠가 안 나와요.
  - P14: 정답표는 월세대출 1개 → 화면은 **0개**예요. 월세대출이 '해당 없음'이라 띠가 안 나와요.
- **P02 미래적금 배지는 "가능 · 전환 필요"예요.** 정답표의 ○와 같은 뜻이에요. 가입 중인 도약계좌와 동시에 가입할 수 없어서 붙는 표시예요.
- **'가입 중' 카드는 상태 칩 개수에 안 들어가요.** 그래서 P14 적금 탭은 탭 숫자가 1인데 상태 칩(가능·확인 필요·해당 없음)은 모두 0이고 흐리게 보여요.

## 6. 이 표를 만든 방법

- 2026-11-16, `main` `636a4e2` 기준이에요.
- 프로필 입력값을 화면 선택지로 바꾼 뒤(`lib/session/__tests__/input-profiles.test.ts`와 같은 방법), 화면 코드와 같은 순서(`draftToUserInput` → `judgeAll` → `buildResultView`)로 돌렸어요. `judgeAll`은 판정 API(`/api/judge`)와 같은 호출이에요. 임시 스크립트로 돌렸고, 저장소에는 넣지 않았어요.
- 나이 경계 4개는 1번 표의 11-16 날짜로 돌렸어요.
- 20개 모두 정답 칸(상태)·가입 중·중복 경고가 정답 프로필과 같았어요.
- 이건 코드로 미리 돌린 결과예요. 실제 브라우저에서 눌러 본 결과는 3번 표의 '화면 결과' 칸에 적어요.
